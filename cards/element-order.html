元素的階

Order of an Element

英文定義

The order of an element a in a group G is the least positive integer n such that aⁿ = e. If no such n exists, a has infinite order.

中文解釋

元素的階 ord(a) 等於 ⟨a⟩ 的元素個數。若 ord(a) = n < ∞，則 ord(aᵏ) = n / gcd(n,k)。理由是 (aᵏ)ᵐ = e 等價於 n 整除 km。

算例

在模 12 加法群 ℤ₁₂ 中，8 的連續倍數依序為 8、4、0，所以 ord(8) = 3。把 8 寫成 1 的 8 倍，也可用 12 / gcd(12,8) = 3 得到同一結果。

常見錯誤

找到某個指數使元素回到單位元素，就直接當作階。例子中 6 · 8 也等於 0，但階要取最小正整數 3。
